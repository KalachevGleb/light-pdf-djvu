# LightView

[English](README.md) | **Русский**

Лёгкий и быстрый просмотрщик PDF и DjVu для Windows. Нативное Win32-приложение на C++:
без фреймворков, служб, апдейтеров, телеметрии и сетевых запросов.

- **PDF** — движок PDFium (тот же, что в Chrome), готовая сборка
  [pdfium-binaries](https://github.com/bblanchon/pdfium-binaries); `pdfium.dll` подгружается только при открытии PDF.
- **DjVu** — DjVuLibre, собирается из исходников статически в `lightview.exe`.

Окно готово примерно через 0,1 с после запуска, даже для PDF на 640 страниц и DjVu на 1000 страниц.
Страницы рисуются в фоновом потоке плитками и кешируются, поэтому прокрутка не тормозит.

## Скачать

Готовые сборки лежат на странице [Releases](../../releases): распакуйте архив
`LightView-*-win-x64.zip` в любую папку и запустите `lightview.exe`. Нужна Windows 10 или 11 (x64),
устанавливать ничего не требуется.

## Возможности

- Непрерывная прокрутка, разворот (две страницы, обложка отдельно), поворот.
- Масштаб: по ширине, страница целиком, реальный размер, Ctrl+колесо (относительно курсора).
- Оглавление (закладки PDF и DjVu) в боковой панели; ширина панели меняется перетаскиванием.
- Поиск по тексту PDF и текстовому слою DjVu: без учёта регистра, `ё` = `е`, переносы в конце строки склеиваются.
  Ищет в фоне, подсвечивает все совпадения.
- Выделение текста мышью, двойной щелчок — слово, Ctrl+A / Ctrl+C.
- Ссылки: внутренние переходы и внешние URL. Перед открытием локальных файлов и нестандартных схем
  LightView спрашивает подтверждение.
- Возврат к прежнему месту боковыми кнопками мыши «Назад»/«Вперёд» (или Alt+←/Alt+→). Точка
  запоминается перед переходом по ссылке, пункту оглавления, номеру страницы, Home/End и перед прыжком
  полосой прокрутки больше чем на полэкрана. Восстанавливается точное положение, включая горизонтальное.
- «Чёткий текст в PDF» (включён по умолчанию, переключается в меню по правой кнопке). PDFium не
  применяет хинтинг к шрифтам Type1/CFF, а их использует большинство PDF из LaTeX, поэтому без
  компенсации буквы выглядят серыми и размытыми. LightView включает субпиксельное сглаживание
  (если в Windows включён ClearType) и гамма-коррекцию, возвращающую контраст штрихов. Побочный
  эффект: полутона на иллюстрациях становятся немного темнее. На печать это не влияет.
- Печать: диапазоны страниц, копии, автоповорот альбомных страниц, уменьшение до размера листа.
- Ночной режим (инверсия в тёмно-серые тона), полный экран.
- Запоминает для каждого файла страницу, масштаб, поворот и разворот, а также положение окна.
- Автоматически перезагружает файл, если он изменился на диске (удобно с LaTeX). Файл не блокируется.
- Повторное открытие уже открытого файла выводит на передний план его окно.
- Светлая и тёмная тема (по настройке Windows), поддержка мониторов с разным масштабом (Per-Monitor DPI v2).

## Сборка

Нужны Visual Studio 2022 с компонентом «Разработка классических приложений на C++» (в него входят
MSVC, CMake и Ninja) и доступ в интернет при первой конфигурации: CMake скачивает PDFium и DjVuLibre
с проверкой SHA-256 в `build/*/_deps`.

Из «x64 Native Tools Command Prompt for VS 2022» в корне проекта:

```bat
cmake --preset release
cmake --build --preset release
cmake --install build/Release --prefix dist
```

Готовая портативная папка — `dist/`: `lightview.exe`, `pdfium.dll` и лицензии. Её можно переносить
куда угодно. Visual C++ Redistributable не нужен: CRT слинкована статически.

Отладочная сборка: `cmake --preset debug && cmake --build --preset debug`.

На GitHub сборку выполняет [Actions](.github/workflows/build.yml): при каждом push и pull request
собирается архив и прикладывается к запуску как артефакт. Чтобы выпустить релиз, отправьте тег вида
`v0.1.0` (`git tag v0.1.0 && git push origin v0.1.0`) — архив `LightView-0.1.0-win-x64.zip` появится
на странице Releases.

## Установка как программы по умолчанию

LightView ничего не устанавливает. Чтобы он появился в «Открыть с помощью» для `.pdf`, `.djvu`, `.djv`,
выполните `lightview.exe --register` или выберите в контекстном меню «Открывать PDF и DjVu в LightView…».
Регистрация пишется только в `HKCU\Software\Classes`, права администратора не нужны. Затем: правый щелчок
по файлу → «Открыть с помощью» → «Выбрать другое приложение» → LightView → «Всегда использовать».
Отменить регистрацию: `lightview.exe --unregister`.

## Настройки

Файл `LightView.ini` хранится рядом с `lightview.exe`, если папка доступна для записи (портативный режим),
иначе в `%APPDATA%\LightView`. В нём положение окна, режимы и история последних 300 файлов.

## Проверка движков

Консольный тест открывает все PDF/DjVu в папке, рендерит первую страницу, извлекает текст, ссылки
и оглавление и печатает время каждой операции:

```bat
cmake --build --preset release --target lightview_smoke
build\Release\bin\lightview_smoke.exe "D:\Книги" --compare
build\Release\bin\lightview_smoke.exe --print book.djvu out.pdf 1 3
build\Release\bin\lightview_smoke.exe --links paper.pdf 1
```

`--compare` сверяет размеры страниц DjVu, прочитанные напрямую из файла (быстрый путь), с данными
DjVuLibre. `--print` печатает страницы через «Microsoft Print to PDF» без диалогов.

## Устройство

| Файл | Назначение |
| --- | --- |
| `src/document.*` | Общий интерфейс документа, кеш текста и ссылок, нормализация текста для поиска |
| `src/pdf_document.cpp` | PDFium: чтение файла без блокировки, прерываемый рендер, формы, текст, ссылки, оглавление |
| `src/djvu_document.cpp` | DjVuLibre: быстрый разбор размеров страниц, рендер фрагментов, текстовый слой, ссылки, оглавление |
| `src/renderer.*` | Фоновый поток рендера, плитки 1024×1024, LRU-кеш с бюджетом памяти, отмена ненужных задач |
| `src/canvas.*` | Область просмотра: раскладка, прокрутка, масштаб, отрисовка, выделение, ссылки, поиск, история |
| `src/toolbar.*` | Панель инструментов (иконки Segoe MDL2 Assets) |
| `src/main_window.*` | Главное окно, оглавление, команды, меню, автоперезагрузка, регистрация типов файлов |
| `src/print.*` | Печать |
| `src/settings.*`, `src/theme.*`, `src/util.*` | Настройки, тема, утилиты |
| `cmake/*.cmake` | Загрузка и сборка PDFium и DjVuLibre |
| `tools/make-icon.ps1` | Генерация `res/lightview.ico` |

## Ограничения

- Только просмотр: без редактирования, аннотаций и заполнения форм. Заполненные формы отображаются.
- XFA-формы не поддерживаются (сборка PDFium без XFA и JavaScript).
- DjVu-страницы с JPEG-слоями (`BGjp`/`FGjp`, встречаются очень редко) показываются без этих слоёв:
  DjVuLibre собрана без libjpeg.
- PDF больше 4 ГБ не открываются.
- Печать растровая, не больше 300 dpi.
